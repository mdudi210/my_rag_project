AuthPoint Hardware Token






























Traditional Authentication That Adapts to Any Business


AuthPoint time-based hardware tokens provide an additional level of security by generating secure one-time passwords (OTPs) every 30 seconds. Businesses and organizations are more frequently adopting multi-factor authentication (MFA) to protect themselves against cyberattacks, and hardware tokens can act as an effective backup layer. These small physical devices can be easily carried in a pocket or on a keychain and generate a unique code for each login attempt.






 






 








Secure OTP Authentication


Hardware tokens provide maximum flexibility when MFA is a priority but the use of personal devices is limited or restricted. The conveniently designed hardware device is ready to provide one-time password (OTP) authentication with minimal configuration steps.










 






 








Token Seeds Are Never Exposed


The authentication process using AuthPoint hardware tokens is Cloud-based, ensuring that sensitive data is not exposed. Seed files are created in a secure network that is isolated from the Internet. These files are then automatically transferred to the Cloud without any human intervention, which means that they are never exposed or exported. As a result, no one inside or outside the company will be able to access them.










 






 








Fast User Token Provisioning


Rapid user provisioning ensures a seamless and efficient onboarding process for everyone. Our self-service portal simplifies the management of token tasks, enabling users to self-associate and activate tokens without the need for technical support.










 






 








Third-Party Token Support


WatchGuard takes designs and produces its proprietary hardware tokens through cutting-edge technology. The seed, a critical component of our security measures, is safeguarded with the utmost confidentiality and is never shared or exposed. We also support any third-party hardware tokens that adhere to the OATH TOTP compliance standards.
